How bulk import works

  • Download the template CSV for the entity you want to import.
  • Fill in the data — the first row (headers) must stay unchanged.
  • Existing records (matched by ISO code / name) are skipped — no duplicates.
  • Import order matters: Countries → States → Cities → Schools → Campuses → Programs.
